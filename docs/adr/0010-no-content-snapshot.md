# ADR-0010: ファイル本文はスナップショットせず、hash ＋ 行数 ＋ 見出し構造のみ保持する

- Status: Accepted
- Date: 2026-09-24

## Context

- 過去時点との比較のために本文を `harness.json` に入れる案があったが、skills は同梱ファイルを含めると大きくなりうる。レビューしたくなるほどのハーネスは膨大なファイルを持っていてもおかしくない。

## Decision

- `harness.json` の各ファイルには本文を入れず、`sha256`、行数、概算トークン数、見出し構造、frontmatter を持つ。
- 「前回から変わったか」は hash で判定する。内容の差分は git / diff に委ねる。
- HTML でも本文は表示せず、パスと要約を示す。

## Consequences

- (+) `harness.json` と HTML が肥大しない。
- (−) 過去時点の本文はこのツール単体では復元できない（対象が git 管理されていれば可能）。
